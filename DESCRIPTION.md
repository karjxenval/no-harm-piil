# Repository description

No-Harm Physics-Informed Inverse Learning (PIIL) provides a certification-and-selection wrapper for learned inverse solvers. A learned physics-informed reconstruction is accepted only when its residual-calibrated radius is no worse than the baseline radius; otherwise the method returns the baseline. The repository contains public-PDE benchmark validation code, controlled inverse-problem stress tests, a no-harm sufficiency sweep, and an optional 3D Navier--Stokes stress test.

Suggested short GitHub description:

> Residual-certified no-harm selection for physics-informed inverse learning: reconstruct, certify, and select.
