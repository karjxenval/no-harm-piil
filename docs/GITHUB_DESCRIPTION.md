## Short description

Residual-certified no-harm selection for physics-informed inverse learning: reconstruct, certify, and select.

## Longer description

This repository accompanies a manuscript on No-Harm Physics-Informed Inverse Learning (PIIL). The core rule accepts a learned physics-informed inverse reconstruction only when its residual-calibrated certificate is no worse than the baseline certificate; otherwise the method falls back to the baseline. The repository includes public PDE benchmark validation, controlled inverse-problem stress tests, a 21,000-trial sufficiency sweep, and an optional 3D Navier--Stokes stress test.
