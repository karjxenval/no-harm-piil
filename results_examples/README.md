# Example result evidence

This folder contains uploaded smoke and quick run tables/metadata from the 3D Navier--Stokes validation script.

- `ns3d_quick_uploaded/`: user quick run, N=24.
- `ns3d_smoke_uploaded/`: user smoke run, N=16.
- `generated_smoke_zip/`: zipped smoke-test outputs generated during script development, where available.

The local figure files listed by the user were on the user's Windows machine and are not embedded here unless separately uploaded. Re-running the scripts regenerates the figures.

- `repo_smoke_verified/`: smoke run produced from the packaged, rectified repository script during final validation.
